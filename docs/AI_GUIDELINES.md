# AI GUIDELINES

Toda IA utilizada neste projeto deve seguir estas regras.

Nunca modificar código automaticamente.

Sempre explicar antes.

Sempre preservar compatibilidade.

Sempre considerar arquitetura existente.

Sempre pensar em escalabilidade.

Sempre considerar centenas de empresas.

Sempre manter baixo acoplamento.

Sempre utilizar composição.

Nunca duplicar lógica.

Sempre preferir Services.

Sempre preferir Providers.

Sempre preferir Repositories.

Sempre responder com:

Arquivo completo.

Nunca enviar apenas trecho.

Sempre informar caminho completo.

Sempre considerar todo o projeto antes de responder.
